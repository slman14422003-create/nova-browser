# Nova Browser

متصفح ويب أندرويد بتصميم Material 3 (ألوان ديناميكية Material You) مبني بـ Kotlin و Jetpack Compose.

## المزايا
- شريط عنوان سفلي بشكل كبسولة (سهل الوصول بيد واحدة)
- تبويبات متعددة في Bottom Sheet
- صفحة بداية، شريط تقدم متحرك، دعم الوضع الداكن
- بحث تلقائي عبر Google عند كتابة نص عادي
- يفتح روابط http/https من التطبيقات الأخرى

## التشغيل
افتح المشروع في Android Studio ثم Run، أو ارفعه إلى GitHub وسيبني GitHub Actions ملف APK تلقائياً (Actions ← Artifacts).

## ميزات الـ WebView
تنزيل الملفات، رفع الملفات (وكاميرا/ميكروفون)، الموقع الجغرافي، السحب للتحديث، البحث في الصفحة،
نسخة سطح المكتب، ضغطة مطولة على الروابط والصور، مشاركة/نسخ الرابط، صفحة خطأ مخصصة،
فيديو بملء الشاشة، حوارات JavaScript، استعادة التبويبات عند إعادة فتح التطبيق، فتح روابط intent:// بأمان.

## مدير التنزيلات
تنزيل متعدد الاتصالات (حتى 16) على نمط IDM/ADM: ملف فارغ بالحجم الكامل يُنشأ مسبقاً ثم يُقسَّم إلى أجزاء،
وعند انتهاء جزء يُقسَّم أكبر جزء متبقٍّ تلقائياً. إيقاف/استئناف حتى بعد إغلاق التطبيق، خدمة أمامية بإشعار تقدّم.
الملفات في Download/Nova. الحد الأدنى للنظام: أندرويد 10.

## الأداء والذاكرة المؤقتة (الإصدار 1.1)
- **تنظيف عند كل تشغيل:** أثناء شاشة البداية (Splash) يُحذف الكاش المؤقت وكاش الـ WebView قبل إنشاء أي تبويب (`CacheCleaner.java`). لا يمسّ الكوكيز ولا التنزيلات ولا التبويبات. قابل للإيقاف من الإعدادات.
- **حجب الإعلانات والمتتبعات** (قائمة نطاقات خفيفة)، **تحميل كسول للصور**، **توفير البيانات** (بدون صور).
- **حماية من الانهيار:** إعادة إنشاء الصفحة تلقائياً إذا انهارت عملية العرض.
- **إدارة الذاكرة:** عند ضغط الذاكرة تُحرَّر تبويبات الخلفية وتُعاد عند الرجوع إليها.
- فحص Safe Browsing وتسخين المحرك مبكراً، وضبط التسريع بالعتاد.
- عرض حجم الكاش مع زر «مسح الذاكرة المؤقتة الآن» في الإعدادات.
- أداة فحص قبل البناء: `python3 tools/project_check.py`.

## الأمان والخصوصية (الإصدار 1.2)
- **Safe Browsing** مفعّل (Manifest + WebView): تُحظر المواقع الخطيرة ويُعاد المستخدم لصفحة آمنة.
- **HTTPS أولاً:** ترقية روابط http إلى https مع رجوع تلقائي إن لم يدعمه الموقع، مع حماية من حلقات التحويل.
- **رفض أخطاء الشهادات** دائماً مع صفحة تحذير (لا زر «متابعة على أي حال»).
- **مكافحة التتبع:** إزالة utm/fbclid/gclid من الروابط، حجب متتبعات الطرف الثالث، حظر كوكيز الطرف الثالث.
- **تحذير قبل تنزيل الملفات التنفيذية** (apk, exe, jar ...).
- **حماية الشاشة** (FLAG_SECURE) اختيارية، و`allowBackup=false`، وإغلاق الوصول إلى الملفات والمحتوى من الـ WebView.
- **سجل الأمان** وفحص إرشادي لسلامة الجهاز (Debugger / Root / Frida) في الإعدادات.
- `python3 tools/project_check.py` يتضمن الآن تدقيقاً أمنياً للـ Manifest.

## حماية التتبع والبصمة + تحسين الأداء (الإصدار 1.3)
- **قائمة حجب موسّعة** في `app/src/main/assets/blocklist.txt` (~150 نطاق إعلانات/تتبع، تشمل نطاقات اختبار EFF) + حجب النطاقات الفرعية مثل `ads.` و`tracker.` و`pixel.`. يمكن تعديل القائمة دون لمس الكود.
- **الحماية من البصمة** (`assets/privacy.js`) تُحقن قبل سكربتات الصفحة: ضجيج Canvas، توحيد/إخفاء WebGL وعدد الأنوية والذاكرة والبطارية والشبكة، تشويش الصوت والخطوط، وتقليل بيانات User-Agent Client Hints.
- **Do Not Track + Global Privacy Control** (ترويسات + `navigator`).
- **الذاكرة:** سقف لعدد الصفحات الحيّة حسب رام الجهاز، تحرير الأقدم مع حفظ حالته (السجل والتمرير) وإعادتها عند الرجوع.
- **المعالج:** إيقاف التبويب غير الظاهر، وإيقاف مؤقتات الصفحات عند الخروج من التطبيق (قابل للإيقاف)، وتقليل تحديثات شريط التقدم.
- **تسريع التشغيل:** `profileinstaller` (Baseline Profiles). وإزالة `LAYER_TYPE_HARDWARE` لأنه كان يزيد استهلاك الذاكرة.

## اللغة والعرض + بصمة أقوى (الإصدار 1.4)
- **لغة التطبيق** (تلقائي / العربية / English): كل نص يمر عبر `L()` مع قاموس في `I18n.kt`، واتجاه الواجهة (RTL/LTR) يتبع اللغة، وتتغير فوراً دون إعادة تشغيل. `LangUtil.java` يحدد الاتجاه وترويسة `Accept-Language`.
- **لغة المواقع:** تُرسل كـ `Accept-Language` وتُعرض في `navigator.language(s)`.
- **حجم الخط في المواقع** (`textZoom`) و**الوضع الداكن للمواقع** (يتبع وضع النظام الداكن).
- **ترجمة الصفحة** من قائمة ⋮ عبر Google Translate (يُرسل عنوان الصفحة إلى Google).
- **بصمة:** ضجيج WebGL (`readPixels` + تصدير Canvas) وOffscreenCanvas والصوت (`copyFromChannel` وAnalyser)، وكل قسم في السكربت معزول بـ try/catch.
- `tools/project_check.py` يتحقق الآن من وجود ترجمة إنجليزية لكل نص `L("...")`.

## التوقيع و GitHub Actions والواجهة (الإصدار 1.5)
- **توقيع الإصدار** بمفتاح ثابت: متغيرات بيئة في CI أو `keystore.properties` محلياً (انظر `docs/SIGNING.md`). بدون مفتاح يُوقَّع بمفتاح debug كي لا يفشل البناء.
- **GitHub Actions:** `build.yml` (فحص Python + Lint + اختبارات + APK debug/release + ملخص + رفع التقارير) و`release.yml` (وسم `v*` → APK/AAB موقّعان + SHA256 + تحقق apksigner + attestation + GitHub Release) و`codeql.yml` (فحص أمني أسبوعي) و`dependabot.yml`، مع قوالب Issues وPR و`SECURITY.md`.
- **مكتبات/بناء:** `androidx.browser` (Chrome Custom Tabs)، `localeFilters` (عربي/إنجليزي فقط لتقليل الحجم)، تخزين Gradle المؤقت والتوازي، ونسخة debug بمعرّف `.debug` تتعايش مع الإصدار.
- **مزايا:** طباعة/حفظ PDF، فتح الصفحة في Chrome (لتسجيل الدخول الذي يرفضه WebView)، لغة التطبيق لكل تطبيق في إعدادات أندرويد 13+ (`locales_config.xml`).
- **الواجهة:** أزرار 48dp بدور Button وأوصاف وصول، تحذير بصري لصفحات HTTP، شارة `99+` لعدد التبويبات، وقائمة ⋮ قابلة للتمرير على الشاشات القصيرة.
- اختبارات وحدة JUnit لـ `LangUtil` و`CacheCleaner`.
