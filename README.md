# Nova Browser

متصفح ويب أندرويد بتصميم Material 3 (ألوان ديناميكية Material You) مبني بـ Kotlin و Jetpack Compose.

## المزايا
- شريط عنوان سفلي بشكل كبسولة (سهل الوصول بيد واحدة)
- تبويبات متعددة في Bottom Sheet
- صفحة بداية، شريط تقدم متحرك، دعم الوضع الداكن
- بحث تلقائي عبر Google عند كتابة نص عادي
- يفتح روابط http/https من التطبيقات الأخرى

## التشغيل
افتح المشروع في Android Studio ثم Run، أو ارفعه إلى GitHub وسيبني GitHub Actions ملف APK تلقائياً (Actions ← Artifacts).

## ميزات الـ WebView
تنزيل الملفات، رفع الملفات (وكاميرا/ميكروفون)، الموقع الجغرافي، السحب للتحديث، البحث في الصفحة،
نسخة سطح المكتب، ضغطة مطولة على الروابط والصور، مشاركة/نسخ الرابط، صفحة خطأ مخصصة،
فيديو بملء الشاشة، حوارات JavaScript، استعادة التبويبات عند إعادة فتح التطبيق، فتح روابط intent:// بأمان.

## مدير التنزيلات
تنزيل متعدد الاتصالات (حتى 16) على نمط IDM/ADM: ملف فارغ بالحجم الكامل يُنشأ مسبقاً ثم يُقسَّم إلى أجزاء،
وعند انتهاء جزء يُقسَّم أكبر جزء متبقٍّ تلقائياً. إيقاف/استئناف حتى بعد إغلاق التطبيق، خدمة أمامية بإشعار تقدّم.
الملفات في Download/Nova. الحد الأدنى للنظام: أندرويد 10.

## الأداء والذاكرة المؤقتة (الإصدار 1.1)
- **تنظيف عند كل تشغيل:** أثناء شاشة البداية (Splash) يُحذف الكاش المؤقت وكاش الـ WebView قبل إنشاء أي تبويب (`CacheCleaner.java`). لا يمسّ الكوكيز ولا التنزيلات ولا التبويبات. قابل للإيقاف من الإعدادات.
- **حجب الإعلانات والمتتبعات** (قائمة نطاقات خفيفة)، **تحميل كسول للصور**، **توفير البيانات** (بدون صور).
- **حماية من الانهيار:** إعادة إنشاء الصفحة تلقائياً إذا انهارت عملية العرض.
- **إدارة الذاكرة:** عند ضغط الذاكرة تُحرَّر تبويبات الخلفية وتُعاد عند الرجوع إليها.
- فحص Safe Browsing وتسخين المحرك مبكراً، وضبط التسريع بالعتاد.
- عرض حجم الكاش مع زر «مسح الذاكرة المؤقتة الآن» في الإعدادات.
- أداة فحص قبل البناء: `python3 tools/project_check.py`.

## الأمان والخصوصية (الإصدار 1.2)
- **Safe Browsing** مفعّل (Manifest + WebView): تُحظر المواقع الخطيرة ويُعاد المستخدم لصفحة آمنة.
- **HTTPS أولاً:** ترقية روابط http إلى https مع رجوع تلقائي إن لم يدعمه الموقع، مع حماية من حلقات التحويل.
- **رفض أخطاء الشهادات** دائماً مع صفحة تحذير (لا زر «متابعة على أي حال»).
- **مكافحة التتبع:** إزالة utm/fbclid/gclid من الروابط، حجب متتبعات الطرف الثالث، حظر كوكيز الطرف الثالث.
- **تحذير قبل تنزيل الملفات التنفيذية** (apk, exe, jar ...).
- **حماية الشاشة** (FLAG_SECURE) اختيارية، و`allowBackup=false`، وإغلاق الوصول إلى الملفات والمحتوى من الـ WebView.
- **سجل الأمان** وفحص إرشادي لسلامة الجهاز (Debugger / Root / Frida) في الإعدادات.
- `python3 tools/project_check.py` يتضمن الآن تدقيقاً أمنياً للـ Manifest.
